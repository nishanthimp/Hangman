# CodeAlpha Hangman Game

## Description

This is a simple console-based Hangman game developed using Python.

The player has to guess a randomly selected word one letter at a time.

## Features

- Contains 5 predefined words
- Randomly selects a word
- Allows 6 incorrect attempts
- Tracks guessed letters
- Detects repeated guesses
- Validates user input
- Console-based gameplay

## Technologies Used

- Python
- Random module
- Lists
- Strings
- While loop
- If-else statements

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python hangman.py
